# Intango Technical Secondary School - Marks Analysis System

## Description

This project is a JavaScript marks analysis system developed for the
Git and GitHub practical assignment.

The system works with fictional student marks and calculates:
- Total marks
- Average mark
- Highest mark
- Lowest mark
- Number of passes
- Number of failures

## Setup

Install Node.js and the project dependencies.

## Execution

Run the JavaScript application according to the instructions provided
in this README.
